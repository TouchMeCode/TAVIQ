# Brand Protection Guidelines

This document expands on [BRAND.md](../BRAND.md). It is a project policy, not legal advice.

## Name and identity

- **Name:** TAVIQ (Thai: ทาวิก)
- **Type:** an independently developed programming language, implemented in Rust
- **Source file extension:** `.tvq`
- **Original creator:** TouchMeCode (<https://github.com/TouchMeCode>)
- **Project organization:** T&N Control (supporting and maintaining organization; see
  [PROJECT_GOVERNANCE.md](PROJECT_GOVERNANCE.md))
- **Official repository:** <https://github.com/TouchMeCode/TAVIQ>

If the official repository moves, this document and the README will be updated, and the old
location will point to the new one.

## Logo usage

TAVIQ has no official logo yet. Until one is published here:

- No image is the official TAVIQ logo.
- Do not present any logo as the official TAVIQ logo.

When an official logo is published, this section will specify the approved files, colors, minimum
size, and permitted uses. Existing logos must not be altered without the original creator's
permission.

## Official affiliation

Only the original creator, or someone the original creator authorizes, may:

- Describe a product, service, event, or organization as official, endorsed, or affiliated with
  TAVIQ.
- Publish official TAVIQ releases.
- Speak on behalf of the TAVIQ project.

Nobody else may imply official affiliation, endorsement, or partnership.

## Forks and modified distributions

| Situation | Guidance |
| --- | --- |
| Fork for personal use or development | Permitted. No special naming is required. |
| Public fork | State that it is a fork and link to the official repository. |
| Modified version distributed to others | Keep the required copyright and license notices. Use a different name, or a descriptive form such as "X, based on TAVIQ". Do not call it "TAVIQ" alone. |
| Product that embeds TAVIQ unmodified | May say that it includes or uses TAVIQ. |
| Extension or integration | May say that it is "for TAVIQ" or "works with TAVIQ". Do not use "Official TAVIQ ..." without permission. |

## Copyright versus trademark

- **Copyright** protects the source code and documentation as written works. The licenses grant
  permission to copy, modify, and distribute them.
- **A trademark** identifies who a product comes from. It protects the name or logo, not the
  code. Neither MIT nor Apache-2.0 grants trademark rights.
- A person can therefore legally fork and modify the TAVIQ code while still being expected not to
  present the result as the official TAVIQ project.

## Reporting misuse

Report suspected misuse of the TAVIQ name by opening an issue in the official repository, or by
contacting the original creator through GitHub.
